## The problem

Vehicle telemetry arrives faster than the React Native JS thread can redraw. A naive implementation drops frames the moment the engine does anything interesting.

## The build

The bus is read in a Nitro Module and handed to the UI thread without serializing through JSON. Gauges are drawn with Skia from Reanimated shared values, so a frame never waits on React.

The full writeup, with the numbers, is on the blog: [Beyond 60 fps](/blog/beyond-60-fps).
